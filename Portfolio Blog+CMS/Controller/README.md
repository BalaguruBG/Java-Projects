# Controller

This folder contains the controller classes responsible for handling incoming HTTP requests in the Spring Boot application.

## Responsibilities
- Handle requests from users.
- Map URLs to appropriate application methods.
- Connect frontend pages with backend services.
- Return the required views or responses.

## Example Routes
| Route | Purpose |
|---|---|
| `/` | Displays the portfolio homepage |
| `/admin` | Opens the admin login or dashboard page |

## Technologies
- Java
- Spring Boot
- Spring MVC
- `@Controller`
- `@GetMapping`
- `@PostMapping` (if implemented)
