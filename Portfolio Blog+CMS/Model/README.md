# Blog

This folder contains the blog-related components of the Portfolio and Blog CMS application.

## Purpose
To manage blog content and make published posts available on the portfolio website.

## Responsibilities
- Represent blog-related data.
- Store blog information such as title, content, and publication details.
- Support blog creation and management.
- Provide blog data for displaying posts on the website.

## Technologies
- Java
- Spring Boot
- Spring Data JPA (if used)
- MySQL
- Entity Mapping (if implemented)
