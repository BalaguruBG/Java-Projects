# Service

This folder contains the service-layer classes responsible for handling the application's business logic.

## Responsibilities
- Process application-related operations.
- Perform business logic separately from controllers.
- Coordinate with repository classes to access database information.
- Handle blog-related operations such as creating, retrieving, updating, and deleting blog posts (where implemented).

## Purpose

The service layer helps maintain separation of concerns by keeping business logic outside controller classes.

## Technologies
- Java
- Spring Boot
- Service Layer Architecture
- `@Service`
