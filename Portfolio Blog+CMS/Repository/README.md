# Repository

This folder contains the repository interfaces responsible for communicating with the database in the Portfolio and Blog CMS application.

## Responsibilities
- Perform database operations.
- Retrieve blog records from the database.
- Save new blog posts.
- Update existing blog information.
- Delete blog records.
- Provide database access methods to the service layer.

## Purpose

The repository layer separates database access logic from business logic, keeping the application organized and maintainable.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- `JpaRepository`
