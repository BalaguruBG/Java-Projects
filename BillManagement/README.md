# Bill Management System

A Java-based console application that allows users to select hotels, view available dishes, place food orders, and generate bills based on ordered items and quantities.

## Features

- View available hotels
- Browse dishes and their prices
- Select dishes and specify quantities
- Manage ordered dishes
- Calculate individual dish totals
- Generate the final bill
- Display the overall order amount
- Handle date and time information
- File handling for storing data

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Map.Entry
- LocalDate & LocalTime
- File Handling (FileWriter & BufferedWriter)
- Multithreading (Thread.sleep)
